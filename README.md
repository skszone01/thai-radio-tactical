# ว.TACTICAL | ระบบฝึกปฏิบัติการรหัส ว. วิทยุสื่อสาร

เว็บแอปพลิเคชันสื่อการสอนและฝึกความชำนาญการใช้ **รหัส ว. วิทยุสื่อสาร** (ตำรวจ / ราชการ / กู้ภัย / อาสาสมัคร / ประชาชน) ออกแบบในสไตล์ **Tactical Field Manual** เรียบคม อ่านง่าย รองรับทั้งบน **Desktop** และ **Mobile** พร้อมรองรับการโฮสต์บน **GitHub Pages** แบบ 100%

## ฟีเจอร์หลักครบทั้ง 4 ระบบ

1. **หน้าแรก รวมคำสั่งวอ (`#directory`)**:
   - รวบรวมรหัส ว. ตั้งแต่ `ว.0`, `ว.00`, `ว.01`, `ว.1` ถึง `ว.65` และหมวด `ว.100` ถึง `ว.621`
   - ตารางเทียบระดับความชัดเจนของสัญญาณ **ว.16 (ระดับ 1 ถึง 5)** และตารางการขานพยัญชนะไทยทางวิทยุ (**ก.ไก่ ถึง ฮ.นกฮูก**)
   - ระบบค้นหาอัจฉริยะ (กด `/` เพื่อค้นหาทันที) กรองตามหมวดหมู่ พร้อมแผงตรวจสอบบริบทสนาม ตัวอย่างประโยคถาม-ตอบ และเสียงสังเคราะห์วิทยุสื่อสาร (Web Audio API PTT Squelch & Roger Beep)
2. **หน้าตัวอย่างการใช้ วอ สื่อสาร (`#scenarios`)**:
   - สรุปโครงสร้างประโยควิทยุมาตรฐาน 4 ขั้นตอน (`ผู้รับ` -> `จาก ผู้ส่ง` -> `เนื้อหารหัส ว.` -> `เปลี่ยน`)
   - สถานการณ์จำลองการสื่อสารจริง 5 รูปแบบ พร้อมปุ่มกดฟังเสียงสนทนาต่อเนื่อง (`PLAY ALL`) และปุ่มสลับดูคำแปลภาษาพูดปกติ
   - เครื่องมือฝึกแต่งประโยคขานวิทยุมาตรฐาน (Tactical Callsign Composer)
3. **หน้าแบบฝึกหัด วอ หลายระดับ (`#drills`)**:
   - **ระดับ 1 (Basic Cadet)**: รหัสหลักที่ใช้บ่อยที่สุดในชีวิตประจำวัน
   - **ระดับ 2 (Field Operator)**: รหัสเชิงลึกและรหัสคู่แฝดที่มักสับสน (เช่น `ว.21` / `ว.22` / `ว.23` / `ว.25`)
   - **ระดับ 3 (Tactical Comms)**: โจทย์สถานการณ์จำลองการขานตอบแม่ข่ายและลูกข่าย
   - **ระดับ 4 (Radio Decoder)**: ถอดรหัสข้อความวิทยุที่มีรหัส ว. หลายตัวซ้อนกัน
   - รองรับทั้ง **โหมดตัวเลือก 4 ข้อ** และ **โหมดพิมพ์รหัส ว. ตอบสด**
4. **แบบฝึกจับเวลาในการตอบรหัส วอ (`#timed`)**:
   - **Sprint 60 วินาที**: ตอบให้ได้มากและแม่นยำที่สุดภายใน 60 วินาที
   - **Reflex 5 วินาที/ข้อ**: บีบเวลาตัดสินใจข้อละ 5.00 วินาที
   - **Survival ไร้พ่าย**: เวลาต่อข้อบีบเร็วขึ้นเรื่อยๆ จาก 6.00 วินาที เหลือ 2.50 วินาที
   - วัดความเร็วตอบสนองระดับมิลลิวินาที (`Avg Reaction Time`) พร้อมประเมินระดับความชำนาญเมื่อจบภารกิจ

## วิธีนำขึ้นโฮสต์บน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ `d:\DEV\thai-radio-tactical` ขึ้นไปยังกิ่ง `main`
3. เข้าไปที่เมนู **Settings > Pages** ของ Repository
4. เลือก Source เป็น **Deploy from a branch** และเลือกกิ่ง `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. เว็บไซต์จะพร้อมใช้งานทันทีผ่าน URL ของ GitHub Pages (มีไฟล์ `.nojekyll` และ `404.html` รองรับเรียบร้อยแล้ว)
